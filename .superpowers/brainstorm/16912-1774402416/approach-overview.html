How it works:

  • Sign Up tab shows an "Access Code" field before email/password fields
  • Code is hardcoded (e.g. CREATOR2026) — you text it to testers
  • Wrong code = inline error, no account created
  • Login tab unchanged — existing accounts work normally
  • One constant to flip when you're ready for public signup
